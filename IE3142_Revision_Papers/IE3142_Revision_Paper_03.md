# IE3142 – DevOps Security
## Revision Paper 03
**Duration:** 2 Hours  
**Total Marks:** 75 *(MCQ section intentionally omitted)*

# Question 2 – Structured Questions (25 Marks)

## (i) Threat Modelling – STRIDE Only (8 Marks)

A cloud-based learning platform allows students to log in, view course material, submit assignments and view grades. Lecturers can upload material and change grades. Administrators manage user accounts.

**a)** Identify four important assets. **(2 marks)**  
**b)** Identify four threats using the **STRIDE model only**. **(2 marks)**  
**c)** Suggest one appropriate control for each identified threat. **(2 marks)**  
**d)** Explain why threat modelling should be carried out early in the SDLC. **(2 marks)**

## (ii) CI/CD Security (9 Marks)

A company develops an API application using GitHub. Developers frequently commit changes. The organization wants to detect insecure code, vulnerable dependencies, exposed secrets and insecure infrastructure before production.

**a)** Explain the purpose of a CI/CD pipeline. **(2 marks)**  
**b)** Explain **SAST, SCA and DAST**. **(3 marks)**  
**c)** Identify three security checks that should be included. **(2 marks)**  
**d)** Explain how a Security Gate can stop a high-risk build from reaching production. **(2 marks)**

## (iii) Docker Architecture (8 Marks)

A development team packages a microservice application using Docker.

**a)** What is Docker? Mention two advantages. **(2 marks)**  
**b)** Draw and explain Docker Client, Daemon/Engine, Images, Containers and Registry. **(3 marks)**  
**c)** Explain Image vs Container. **(1 mark)**  
**d)** Identify two Docker security risks and suitable controls. **(2 marks)**

# Question 3 – Essay Question (25 Marks)

A bank is developing a digital banking platform. Security is treated as a final testing activity. The security team discovers SQL injection, poor password protection, unauthorized access, unencrypted sensitive information and insufficient audit logging.

**a)** Explain the Shift-Left approach and how it changes the traditional SDLC security model. **(5 marks)**  
**b)** Explain five secure coding practices that should be applied to the banking platform. Give examples. **(5 marks)**  
**c)** Apply **STRIDE** to identify five threats and recommend suitable controls. **(8 marks)**  
**d)** Explain three infrastructure-security measures suitable for a banking environment. **(3 marks)**  
**e)** Explain how security throughout the SDLC reduces cost and improves security. **(4 marks)**

# Question 4 – Essay Question (25 Marks)

A healthcare provider is building a cloud-based medical-record system. Doctors, nurses and administrators access sensitive patient information. The organization uses GitHub, CI/CD, Docker, Kubernetes and cloud infrastructure. The review identifies exposed credentials, vulnerable images, excessive Kubernetes access, weak monitoring, unclear governance and no incident-response process.

**a)** Explain how security can be integrated at each stage of the CI/CD pipeline. Include suitable security checks and tools. **(6 marks)**  
**b)** Identify four Docker container risks and explain controls for each. **(4 marks)**  
**c)** Explain how Kubernetes RBAC can enforce least-privilege access for developers and administrators. **(4 marks)**  
**d)** Explain the importance of governance and compliance in a healthcare environment. Mention three security controls. **(4 marks)**  
**e)** Explain continuous security monitoring and mention suitable technologies. **(3 marks)**  
**f)** Describe the six incident-response phases for a patient-information breach. **(4 marks)**
