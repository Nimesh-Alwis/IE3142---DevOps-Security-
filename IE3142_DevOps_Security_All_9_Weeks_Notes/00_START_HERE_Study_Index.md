## One-minute master recap

- **DevSecOps:** Security everywhere in SDLC — shared + shift-left + automate + monitor.
- **Secure Coding:** Validate → Parameterize → Encode → Least Privilege.
- **Secure Design:** 12 principles + Threat Model + STRIDE.
- **Infrastructure:** Shared Responsibility + IAM + Network + Hardening + Backup.
- **Containers/Kubernetes:** images, runtime, secrets, RBAC, NetworkPolicy, pod security.
- **CI/CD:** SAST + SCA + secrets + DAST + IaC + security gates.
- **Monitoring/IR:** logs → SIEM/IDS → Detect → Contain → Eradicate → Recover.
- **GRC:** GDPR personal data, HIPAA health data, ENISA guidance.
- **Serverless:** provider manages infrastructure; customer secures code, permissions, APIs, secrets.
